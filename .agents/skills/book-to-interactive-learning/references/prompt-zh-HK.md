# 可重用指令

將以下內容貼到新工作，並附上書本或提供可存取的來源，以及目標 GitHub repository：

> 請使用 $book-to-interactive-learning，根據我提供的書本，直接製作一個互動學習網站，而不只是提供大綱。
>
> 按原書內容安排完整課程，合適的話分成 12–24 課，不要只做六個簡短章節。每課要有原創內容解說、深入分析、完整真實案例、與本課的連繫、假設練習、互動選擇題及答案解釋、記憶卡和反思題。真實案例要交代背景、經過、成因、結果及常見誤解，不要只有幾句介紹。
>
> 提供英文及香港繁體中文，一個按鈕切換整個網站；切換後保留目前章節、閱讀進度、書籤和筆記。每章加入相關圖片及有助理解的解說圖；有可靠數據時加入互動歷史圖表，例如 GameStop 股價圖。圖表標明日期、單位、來源及拆股調整方式；假設數據必須清楚標示。
>
> 使用原創摘要及分析，不公開我上載的 PDF、現代註釋、掃描頁或私人檔案路徑。不要顯示「閱讀你提供的 PDF 第幾頁」之類的提示。保留有用的公開來源連結及作者署名。
>
> 加入準確的私隱、版權和一般投資教育說明。預設不使用追蹤或收集個人財務資料；筆記只保存在瀏覽器，提供匯出及清除功能。不要保證完全沒有法律風險，也不要把內容寫成個人投資建議。
>
> 完成手機及桌面版、中英文及互動功能測試，提供可上載 Cloudflare Pages 的 ZIP。若我已授權更新指定 GitHub repository，請提交及推送；清楚交代哪些部署和線上檢查已完成。

## 使用與安裝

本 repository 已將 Skill 放在 `.agents/skills/book-to-interactive-learning/`。在支援此目錄的 Codex 環境中重新開啟工作後，可用 `$book-to-interactive-learning` 呼叫；是否自動載入以當前環境顯示的可用 Skills 為準。

如要用於另一個 repository，複製整個 `book-to-interactive-learning` 資料夾到該 repository 的 `.agents/skills/`。如環境沒有自動載入，直接要求助手讀取該資料夾的 `SKILL.md` 並依照執行即可。這不代表已安裝到所有聊天或雲端帳戶。
